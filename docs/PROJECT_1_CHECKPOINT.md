# Project 1 — Checkpoint 1

## Goal

Prove that the game can launch as a responsive browser application, move between its first screens and accept both desktop and touch input at the approved 352 × 440 logical resolution.

## Included

- [x] Phaser and TypeScript project structure
- [x] Vite development and production builds
- [x] Responsive 4:5 game canvas
- [x] Title screen
- [x] Hole-introduction screen
- [x] Split overhead and side-view game screen
- [x] Keyboard input
- [x] Touch input with large controls
- [x] Placeholder aim and club selection
- [x] Placeholder three-input swing state sequence
- [x] Pause, restart and exit controls

## Intentionally deferred

- Final character and course sprites
- Tuned shot physics
- Surface collision and lie resolution
- Bounce and rollout simulation
- Water and out-of-bounds penalties
- Putting mode
- Hole completion and final scoring
- Original sound effects

## Next checkpoint

Build an isolated shot sandbox. The player will select a club, aim, complete the three-input meter and produce a deterministic shot result from editable configuration data. The sandbox should expose tuning values before they are connected to the full hole.
